# Via ROMA

Involveds månedlige ROMA-samtale som en interaktiv nettside: 10 minutter per prosjekt, alt er grønt til du flagger noe, og resultatet går rett til Excel i samme oppsett som ROMAsamtaleskjema V1.10.

## Bruk

Åpne `index.html` i en nettleser. Ingen installasjon, ingen server. Alt lagres lokalt i nettleseren; ta sikkerhetskopi (JSON) fra Oversikt-fanen før du bytter maskin.

Publiser gjerne via GitHub Pages (Settings → Pages → branch `main`, mappe `/`), så kan hele teamet åpne den fra én lenke.

## Hva den gjør

- **Dagens runde**: velg 1–3 prosjekter, kjør dem etter hverandre med 10-minutters nedtelling per prosjekt.
- **Alt grønt som standard**: du flagger bare det som er Risiko eller krever tiltak. Forrige måneds flagg ligger klare med «Løst nå».
- **30 screeningspørsmål** i de åtte områdene fra rutinen, med «se etter»-hjelpetekst og strukturerte felt der tall gir bedre oppfølging (timer vs. ramme, åpne endringer, timer per uke, kunde-skala 1–5, sluttdato).
- **Puls**: belastning, trivsel og energi 1–5 med ankertekster og terskler for oppfølging.
- **Røde flagg** som alltid meldes til leder og Planner.
- **Eksport**: Excel per prosjekt (Forside, Prosjektinfo, ROMA-samtale, Tiltak & Oppfølging, Statusoversikt), egen ledereksport med pulsverdier, tekst til Teams, utskrift/PDF.
- **Oversikt**: prosjekter med neste samtale, trend, tiltakslogg og historikk.

## Personvern

Pulsverdier og kommentarer under trivsel og belastning går kun i ledereksporten, ikke i prosjektmappen. Appen ber om at helseopplysninger, navn på personer hos kunde og private forhold tas muntlig, ikke i fritekst.
